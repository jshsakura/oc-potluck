title: "What is PotLuck?"
description: "Choose local or remote play and understand the three components."

PotLuck bridges local wireless multiplayer through LDN MITM. It runs with Atmosphere and uses the game's **local wireless** menu. Every player needs a compatible game and matching game version.

## Choose your setup

| Mode | When to use it | What you need |
| --- | --- | --- |
| Local | Friends in the same home, on the same Wi-Fi | Their Switch also runs PotLuck (or ldn_mitm). No server needed. |
| Remote | Friends far away, over the internet | Everyone enters the same relay address and channel. |
| Off | You don't want PotLuck right now | Nothing. After a reboot the Switch uses its own local wireless again. |

A new install starts in remote mode, but **until you enter a server address it behaves like local mode.** PotLuck ships no public server, so remote play needs a relay that you or a friend runs.

If rooms don't show up in local mode, check the router. Guest Wi-Fi, settings that block devices from talking to each other (AP isolation) and separate networks (VLANs) stop discovery. Local mode uses port 11452 (UDP and TCP) inside your network. The first time you use it, it sets the Wi-Fi profile MTU to 1500 and leaves it there.

## Three components

- **Installer:** a Homebrew Menu app (`potluck-installer.nro`) that installs, updates, configures and removes PotLuck. Close it before playing.
- **Module + overlay:** the resident module handles game network traffic; `potluck.ovl` provides settings and status.
- **Relay + Redis:** Services for remote discovery and relay traffic. Deploy with Docker or [run from source](../relay-native/). Local mode does not need them.

PotLuck does not add multiplayer to single-player games, replace an official online service, or make every supported-list entry a verified compatible game.
