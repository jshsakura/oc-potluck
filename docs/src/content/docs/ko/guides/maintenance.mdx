## 업데이트

게임을 종료하고 설치 앱으로 업데이트하거나 같은 릴리스 ZIP의 모듈·오버레이를 함께 교체한 뒤 재부팅하세요. 직접 수정 전에는 `atmosphere/contents/4200000000504C4B/config.ini`를 백업합니다. 릴리스를 섞지 마세요.

설치 앱은 임시 저장·검증 후 파일을 교체합니다. 중단됐다면 앱을 다시 열고 복구 결과부터 확인하세요. 복구 중에는 `config/potluck_installer/`를 지우지 마세요.

## 설치 앱으로 삭제

게임 종료 후 앱에서 삭제를 고르고 설정 보관 여부를 선택합니다. 이후 재부팅하세요. 설치 때 ldn_mitm을 끈 기록이 있다면 삭제 과정에서 자동 실행을 복원할 수 있습니다. LDN 모듈은 하나만 활성화하세요.

## 직접 삭제

1. 전원을 끄고 SD 카드에 접근합니다. 필요하면 `atmosphere/contents/4200000000504C4B/config.ini`를 백업합니다.
2. `atmosphere/contents/4200000000504C4B/`와 `switch/.overlays/potluck.ovl`을 삭제합니다.
3. 필요 없으면 `switch/potluck-installer.nro`와 `config/potluck/` 로그를 지웁니다. 설치 앱 상태는 진행 중인 복구가 없을 때만 삭제합니다.
4. ldn_mitm으로 돌아가려면 PotLuck을 끄거나 삭제한 뒤에 기존 `flags/boot2.flag`를 복원하세요. 직접 삭제는 설치 앱의 복원 기록을 실행하지 않습니다.

모듈 폴더를 지우면 설정도 삭제됩니다. 잠시 끄려면 PotLuck의 `flags/boot2.flag`만 제거하고 재부팅하세요.

## 부팅 실패

전원을 끄고 SD 카드의 `atmosphere/contents/4200000000504C4B/flags/boot2.flag`를 제거합니다. 다른 LDN 모듈도 켜져 있지 않은지 확인하세요. 정상 부팅 후 같은 릴리스로 재설치합니다. 진단에 필요한 Atmosphere 보고서·최근 PotLuck 로그는 보관하고 관련 없는 Atmosphere 파일은 유지하세요.
