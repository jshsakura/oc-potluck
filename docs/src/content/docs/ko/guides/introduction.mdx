PotLuck은 로컬 통신을 연결하는 LDN MITM 모듈입니다. 게임의 **로컬 통신** 메뉴를 사용하며, 참가자는 호환되는 게임과 같은 게임 버전을 준비해야 합니다.

## 어떤 모드를 고를까요?

| 모드 | 언제 쓰나요 | 무엇이 필요한가요 |
| --- | --- | --- |
| 로컬 | 같은 집, 같은 와이파이에 있는 친구와 할 때 | 친구 스위치에도 PotLuck(또는 ldn_mitm)이 있으면 됩니다. 서버는 필요 없습니다. |
| 원격 | 멀리 있는 친구와 인터넷으로 할 때 | 모두 같은 중계 서버 주소와 채널을 넣어야 합니다. |
| 끄기 | PotLuck을 쓰지 않을 때 | 없습니다. 재부팅하면 스위치 원래의 근거리 통신으로 돌아갑니다. |

처음 설치하면 원격 모드로 되어 있지만, **서버 주소를 넣기 전까지는 로컬 모드처럼 동작합니다.** PotLuck은 공용 서버를 제공하지 않으니 원격으로 하려면 친구나 본인이 연 서버 주소가 필요합니다.

로컬 모드에서 방이 안 보이면 공유기 설정을 의심해 보세요. 게스트 와이파이, 기기끼리 통신을 막는 설정(AP 격리), 서로 다른 네트워크(VLAN)에서는 방을 찾지 못합니다. 로컬 모드는 공유기 안에서 11452번 포트(UDP·TCP)를 씁니다.

## 세 가지 구성 요소

- **설치 앱:** 홈브루 메뉴에서 실행하는 `potluck-installer.nro`입니다. 설치·업데이트·설정·삭제를 맡으며 플레이 전에는 종료해도 됩니다.
- **모듈과 오버레이:** 시스모듈이 게임 통신을 처리하고 `potluck.ovl`에서 설정과 상태를 확인합니다.
- **중계 서버와 Redis:** 원격 방 검색과 통신을 위한 서비스입니다. Docker로 배포하거나 [소스를 빌드해 직접 실행](../relay-native/)할 수 있으며, 로컬 모드에는 필요 없습니다.

싱글플레이 게임에 멀티플레이를 추가하거나 공식 온라인 서비스를 대체하지 않습니다. 지원 목록에 있다고 실기 호환성이 검증된 것은 아닙니다.

[설치](../installation/) → [첫 플레이](../overlay/) 순서로 시작하세요. 서버가 필요하면 [중계 서버 설치](../relay-server/)를 참고하세요.
