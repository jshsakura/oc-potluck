## 로컬 모드로 첫 방 만들기

1. 두 기기를 같은 LAN·와이파이에 연결합니다. 게스트 네트워크와 AP 격리는 피하세요.
2. 게임 실행 전에 양쪽에서 **로컬**을 선택합니다. 호환되는 ldn_mitm 기기도 참가할 수 있습니다.
3. 같은 게임·버전으로 실행하고 **로컬 통신** 메뉴에 들어갑니다. 한 명이 방을 만들고 나머지가 들어갑니다.

Docker 서버·채널·인터넷 포트 전달은 필요 없습니다. 서로 다른 서브넷에는 검색 브로드캐스트가 전달되지 않을 수 있습니다.

## 원격 모드로 첫 방 만들기

1. 운영자에게 연결 가능한 [중계 서버](../relay-server/) 주소·포트를 받습니다.
2. 모든 기기에 같은 서버·포트를 저장하고 **원격**을 선택합니다. 채널도 맞추세요. 빈 값은 공개 채널입니다.
3. **서버 연결 시험** 후 게임을 완전히 종료·재시작하고 로컬 통신 메뉴에서 방을 만들거나 참가합니다.

시험은 서버 접근과 왕복 지연을 확인하며 특정 게임의 전체 멀티플레이 성공을 보장하지 않습니다. P2P를 끄고 두 명으로 먼저 확인하세요.

## 조작과 설정

오버레이 메뉴 단축키(기본 **L + 십자키 아래 + 오른쪽 스틱 클릭**)를 누르고 **potluck.** 을 고릅니다. 상단 카드에 게임 목록 상태·연결·방 인원·확인 가능한 지연 시간이 나옵니다. 한국어 시스템이면 한국어, 나머지는 영어입니다.

| 항목 | 용도 | 적용 시점 |
| --- | --- | --- |
| 모드 | 원격·로컬·끄기 | 원격↔로컬은 게임 완전 재시작 후. 끄기·꺼진 채 부팅 후 활성화는 재부팅 안내 확인 |
| 채널 | 8자리 16진수 검색 그룹, 빈 값은 공개 | 참가자 모두 맞추고 방 재입장 |
| P2P | 선택적인 기기 간 직접 통신 | 다음 방부터. 기본 꺼짐 |
| 다시 연결 | 중계 연결 재시작 | 즉시. 먼저 현재 방에서 나가세요 |
| 서버 / 포트 | 호스트명 또는 IPv4와 TCP 포트 | 저장 후 재연결 안내 확인. 확실한 적용은 게임 재시작 |
| 서버 연결 시험 | 저장된 서버 접근 확인 | 실제 원격 모드에서 제공 |

설정은 자동 저장합니다. 키패드는 십자키+A 또는 터치로 입력하고 **+ / 저장**으로 저장, **B**로 한 글자를 지웁니다. 설치 앱에는 시스템 키보드, 진단, 언어·디버그 설정도 있습니다.

서버 주소가 비면 원격을 골라도 로컬로 동작합니다. 오버레이만 다시 열어서는 이미 실행 중인 게임의 모드가 바뀌지 않습니다. INI 직접 편집·설치 앱 서버 변경 후에는 재부팅하세요. [전체 설정](../configuration/)도 확인하세요.
