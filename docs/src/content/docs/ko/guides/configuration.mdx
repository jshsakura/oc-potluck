## 파일과 기본값

SD 카드의 `atmosphere/contents/4200000000504C4B/config.ini`를 편집합니다. 먼저 백업하고 **직접 편집한 뒤에는 재부팅**하세요. 누락된 옵션은 기본값을 씁니다. `config/ryu_ldn_nx/config.ini`는 이전 버전 마이그레이션 경로이며 현재 편집 위치가 아닙니다.

```ini
[server]
host =
port = 30456

[network]
connect_timeout = 5000
reconnect_delay = 3000
max_reconnect_attempts = 5

[ldn]
mode = remote
passphrase =
disable_p2p = 1

[debug]
enabled = 0
level = 1
```

## 서버·네트워크

| 옵션 | 기본값 / 단위 | 의미 |
| --- | --- | --- |
| `server.host` | 빈 값 | 호스트명 또는 IPv4. INI에서 최대 128자. URL 형식·경로·포트 접미사 금지. 빈 값은 실제로 로컬 모드 |
| `server.port` | `30456` / TCP | 1–65535. 서버가 호스트에 공개한 포트와 일치 |
| `network.connect_timeout` | `5000` / 밀리초 | 연결 시도 제한 시간. 연결 자체가 느린 것이 확인될 때만 늘리세요 |
| `network.reconnect_delay` | `3000` / 밀리초 | 재연결 지연 설정. 복구 진단 외에는 기본값 권장 |
| `network.max_reconnect_attempts` | `5` / 횟수 | `0`은 자동 재연결 끄기이며 무한 재시도가 아닙니다 |

같은 LAN에서는 NAS 내부 IP, 외부에서는 접근 가능한 공인 IP·DDNS를 사용합니다. `redis`, Docker 내부 주소, 이 문서 사이트 URL을 넣지 마세요. 클라이언트에는 **실제 TLS 지원이 없으며 일반 TCP**로 중계합니다.

## 모드·채널·P2P

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| `ldn.mode` | `remote` | `remote`, `local`, `off`. 원격이어도 빈 서버 주소면 로컬 동작 |
| `ldn.passphrase` | 빈 값 | UI는 8자리 16진수. INI는 `Ryujinx-a1b2c3d4`처럼 `Ryujinx-`와 소문자 16진수 8자리를 함께 입력 |
| `ldn.disable_p2p` | `1` | `1` 중계 전용, `0` 선택적인 직접 P2P 허용. 첫 설치는 중계 전용 권장 |

채널은 방 검색 구분이며 암호화·강한 인증이 아닙니다. 참가자 모두 맞추세요. P2P는 상대 네트워크·NAT의 접근 가능성에 영향을 받으며 첫 설치에는 필요 없습니다. 참·거짓 옵션은 `0`/`1`을 쓰세요.

## 디버그

| 옵션 | 기본값 | 의미 |
| --- | --- | --- |
| `debug.enabled` | `0` | `0` 끄기, `1` 켜기. 파일 기록도 이 스위치를 따릅니다 |
| `debug.level` | `1` | `0` 오류, `1` 경고, `2` 정보, `3` 상세 |

문제 재현 때만 잠시 레벨 2를 사용하세요. 상세 로그는 SD 쓰기와 플레이 중 처리를 늘립니다. 로그 위치는 `config/potluck/potluck.log`이며 확인 후 디버그를 끕니다. 설치 앱 디버그 설정은 실행 중인 모듈과 파일에 적용합니다.

## 적용 시점

오버레이는 자동 저장합니다. 원격·로컬 변경은 **게임 완전 종료·재시작**이 필요합니다. 끄기·꺼진 채 부팅 후 활성화는 재부팅 안내를 따르세요. P2P는 다음 방부터, 채널 변경·재연결은 방에서 나간 뒤 진행합니다. 설치 앱의 서버·P2P 변경과 INI 직접 편집 후에는 기기를 재부팅하세요.

## 효과 없는 이전 옵션

`server.use_tls`, `network.ping_interval`, `ldn.interface`, `ldn.enabled`, `[perf]`는 현재 실행 경로의 유효한 조절 옵션이 아닙니다. 이전 `debug.log_to_file`도 독립적이지 않으며 파일 기록은 `debug.enabled`를 따릅니다.
